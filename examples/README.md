# Examples

This directory contains examples of how to use the `border-gradient-radius` component in different scenarios.

## Next.js Example

The file `nextjs-usage.tsx` shows how to use the component in a Next.js application. You can copy this file into your Next.js project's pages or components directory.

To use this example:

1. Install the package in your Next.js project:

   ```bash
   npm install border-gradient-radius
   # or
   yarn add border-gradient-radius
   ```

2. Copy the example file to your project or use it as a reference.

3. Import and use the component as shown in the example.

## TypeScript Support

The package includes TypeScript definitions, so you can use it in TypeScript projects without any additional setup.

## CSS Customization

You can customize the appearance of the gradient border by adjusting the props or adding your own CSS classes.

## Note on Examples

These examples are provided as a starting point and may need to be adapted to your specific project configuration.
